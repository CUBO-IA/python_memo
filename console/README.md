# Tipos de datos en Python — desde cero

Orden recomendado para estudiarlos:

| # | Archivo | Tipo | En una frase |
|---|---|---|---|
| 1 | `integer.py` | `int` | Números enteros: 5, -3, 100 |
| 2 | `float.py` | `float` | Números con decimales: 0.75, 3.14 |
| 3 | `strings.py` | `str` | Texto entre comillas: "hola" |
| 4 | `boolean.py` | `bool` | Verdadero o falso: True / False |
| 5 | `none.py` | `NoneType` | "Nada", sin valor todavía: None |
| 6 | `list.py` | `list` | Varios valores en orden, se pueden cambiar: [ ] |
| 7 | `tuple.py` | `tuple` | Como lista, pero NO se puede cambiar: ( ) |
| 8 | `dictionary.py` | `dict` | Pares clave → valor: {"nombre": "Memo"} |
| 9 | `set.py` | `set` | Valores sin repetir y sin orden: { } |

## Cómo correr cada uno
Desde la terminal, dentro de esta carpeta:

```bash
cd ~/Desktop/cubo_ai_python/console
python3 integer.py
```

En VS Code también podés abrir el archivo y darle al botón ▶️ de arriba a la derecha.
